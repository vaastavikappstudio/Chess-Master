# Chess-Master
Chess Master is a modern, responsive chess game built for players of all skill levels. Challenge yourself against AI or play with a friend — improve your strategy, sharpen your mind, and enjoy one of the world’s oldest and smartest board games in a sleek digital format.
🎮 Features

✅ 1-Player & 2-Player modes

✅ Smart AI opponent with multiple difficulty levels

✅ Undo / Redo moves for better learning

✅ Legal move highlighting and piece hints

✅ Clean and responsive design (works on PC & mobile)

✅ Sound effects & move animations

✅ Game timer and score tracking

🛠️ Tech Stack

Built with HTML, CSS, JavaScript (or your engine: Godot / Unity / etc.)

Lightweight and fully optimized for mobile browsers

Easy to integrate with WebView Android apps or progressive web apps (PWAs)

🚀 Perfect For

Chess lovers and strategy game fans

Learners wanting to improve their tactical skills

Developers showcasing game projects on GitHub

Educational use or logic-based app portfolios
